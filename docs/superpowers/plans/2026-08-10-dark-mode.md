# 暗色模式支持 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Synctrol 占位页添加跟随系统的暗色模式支持（纯黑背景全反转）。

**Architecture:** 在 `style.css` 中引入语义化 CSS 变量（`--bg`、`--fg`、`--bar-bg`、`--bar-fg`、`--border`、灰阶变量、背景层颜色变量），将现有硬编码颜色替换为变量引用，然后新增 `@media (prefers-color-scheme: dark)` 覆盖块。`index.html` 无需改动。

**Tech Stack:** 纯 CSS（CSS 自定义属性、`prefers-color-scheme`、`color-scheme`）。无 JS、无构建工具。
